# @anpdgovbr/sei-client

Pacote reservado para uma futura integração direta com SEI.

Ainda não há contrato operacional implementado. Antes de adicionar código,
defina quais serviços do SEI serão usados, como será feita a autenticação e como
essa integração se diferencia das consultas feitas via SIP.

Este pacote está marcado como `private: true` e não deve ser publicado até o
contrato público ser definido.
